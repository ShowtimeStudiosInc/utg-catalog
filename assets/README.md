# Assets Directory

This directory should contain application icons for the Electron app:

- `icon.png` - PNG icon (256x256 recommended) for Linux
- `icon.ico` - ICO icon for Windows  
- `icon.icns` - ICNS icon for macOS

For now, Electron will use a default icon if these files are not present.
You can create these icons using tools like:
- https://icoconvert.com/
- https://www.favicon-generator.org/
- Image editing software like GIMP or Photoshop
